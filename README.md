# TenkaCloud Interview Catalog

Six versioned JSON catalogs contain 87 original AI-assisted interview-practice lessons. Content is independent of the Passport app; no executable code is downloaded. Reference implementation text is displayed only. Free explanations are self-assessed, and neither mastery nor hiring outcomes are guaranteed.

Current release: **2026.10.1301**. Payloads are immutable at commit `f70fb5a8fb21cae0bcb113a8e7e744f5e824bb35`. Manifests carry schema v1, catalog identity, version, immutable commit, payload path, byte length and SHA256. SHA256 verifies integrity, not publisher identity. Updating requires a new version and commit; existing versions cannot silently change. App downloads are explicit and preserve prior local versions/history.

Source attributions and original AI-assisted authorship are in each lesson. Personal profiles, answers and account credentials are excluded. This repository contains learning data only; app signing, releases and App Store distribution are separate.
